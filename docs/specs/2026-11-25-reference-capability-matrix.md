## 推进规则

先把 P0 的正常聊天路径逐项做完整，再做 P1 的持久规划与角色协作；安全凭据的真实服务与原生设备验收可独立等待外部条件，不阻塞其他本地工作。每项在动手前补单独计划、Pi 扩展点核对和源码执行路径；字段存在或工具定义存在只证明接口，不能直接标为整项完成。目标仍为持续对齐，上表不是参考项目全部能力的穷尽清单。
