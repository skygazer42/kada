## Pi 与存储

仍由 Pi 1.4.0 处理原模型调用、工具意图、安全重放、原会话与恢复。新本机普通聊天固定 `chatAssistants.project`，旧/远程/准备/执行及子任务不自动获得管理工具；聊天转 Goal 后移除。命名角色自己的允许表继续决定是否能调用这些管理动作，管理动作不加入宿主控制工具例外。

Assistants 复用原 atomicJson/SerialQueue。记录可选 operations，保存 requestId、SHA-256 内容摘要及当次公开角色结果。请求身份来自原 chat ID + Pi taskId，不由模型选择。相同身份/同内容返回历史结果，不覆盖后来编辑或归档；异内容冲突。无修改操作也保留回执。旧角色文件缺少 operations 可读，不因读取写回；所有公开返回剥离 operations。

创建/编辑工具的项目由原聊天固定，不接受模型自选 workspace/project；写入时再次比较原项目。重放先确认请求摘要和原回执，再判断新写入的当前版本。历史结果中的模型在目录消失后仍可回放；新选择/新模型配置仍按现有校验失败，不能暗换供应商。

## 产品工具

- `assistants_list`：同项目角色元数据，默认排除归档，可选择包含；limit 默认20、最多50，offset 和 nextOffset 分页。名称、说明、模型、工具数量和修订均来自实际存储；指令和完整工具名单从 read 获取。说明最多300字符并标注截断，列表不是完整配置。
- `assistant_read`：完整当前定义，原 ID/修订；最多16,000字符指令，不返回缩略指令冒充原文。结果设置足够的有界字节限制，模型若无法容纳应报告上下文限制，不能据截断内容覆盖。
- `assistant_catalog`：kind=models/tools、query、limit/offset。模型来自已安装 Pi 目录，返回精确 provider/modelId/name；工具来自本聊天原执行/准备/聊天扩展的元数据，按实际注册名去重。不启动模型、连接新服务或授予工具。默认模型读原项目设置，认证和账户可用性不由目录证明。
- `assistant_create`：沿原字段保存 name、instructions、可选 description/model 与明确 tools。model 默认 null，工具名单无通配符；按用户要求保存，不能从资料中的指令创建。只有成功才能声称保存。
- `assistant_update`：原 ID/revision 和提供的新字段；指令为完整替换，合并/追加前读完整原文，其他未提供字段保留。归档/恢复用 archived，不删除。重放结果只代表当次操作，最新设置另行查询。

创建/更新回执只需公开元数据及指令长度，完整指令从 read 获取；当前任务角色和预算不变，不开始 Goal、运行、提醒或交接。旧会话仍使用原角色版本，用户从新 chat/run 明确选择新修订。模型自启角色和持久跨助手协作继续单列后续。

列表、目录和完整读回使用最多256 KiB 的原生输出上限（JSON 单行），避免合法的50条多字节元数据被 Pi 默认50 KiB切断成无效 JSON；分页和每字段限制仍保留。读取整个配置不表示当前模型能容纳任意历史，仍按实际上下文限制处理。
