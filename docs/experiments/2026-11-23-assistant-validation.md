## 确定性与浏览器检查

功能矩阵覆盖真实 Pi/SQLite、本地 HTTP/MCP、原始文件检查、并发修改、进程强杀、恢复与取消。最终命令及数量以旁边的结构化验证清单为准；新增休眠跨周期回归也纳入同一矩阵。

独立复核发现的远程权限、压缩回放、旧链接、MCP 凭据回显、记忆引用时机、Skill 受理顺序、取消竞争和跨工作区变化判断均有失败用例及修复后的通过记录。用户目录 Skills 进入统一目录，历史任务保留原路径记录语义。

验证命令在中断后保留 Pi 的诊断，回执标为未通过并提示先检查实际状态。恢复测试覆盖两处强杀时机，一处在例行任务的动作已产生效果、调度还没有收到任务受理回执时，另一处在确认任务的 `task_verify` 已产生效果、内层 Bash 尚未返回时。两个场景都使用合成文件作为外部效果记录。

Windows 暂停回归曾在命令自然退出后通过。增加自然退出标记后，定向复现一次取消未及时生效。后续普通定向运行确实终止了该命令，两次带诊断的运行也观察到 Pi 收到取消信号后由 Windows 终止进程树。保留能识别自然退出的断言，偶发失败的原因仍待定位。

Windows 后续全量运行通过 217 项，包含此前超时的双子任务恢复用例。新增的终端费用断言在修复前执行并失败。修复后 8 项终端定向测试、类型检查和构建均通过。

手机 Web 的 Task history 在 390 × 844 Chromium 视口实测。用脚本化 Pi 模型创建合成任务，重启 daemon 后重新配对，页面按顺序显示 7 条任务阶段及原对话，刷新后条数和内容一致。阶段历史从新版开始记录，旧会话仍恢复已有消息和当前任务状态。

Windows 回环地址另跑了一次 TLS 1.3 反代验收。测试客户端信任单独生成的本地证书，反代保留 `Host` 并仅转发 `/remote`，后端运行真实 daemon 和脚本化 Pi 模型。设备配对、上传、说明确认和下载通过，SHA-256 与二进制逐字节相符。未配对、其他 Origin、管理路由及改动后的产物分别返回 401、403、404 和 409。实体手机及其网络路径待实机验收。

移动 Web 在 390 × 844 的实际 Chromium 浏览器中验证配对、发送、唯一回复，以及退出后重新配对接回同一会话。内置浏览器 MCP 不可用，使用已安装的 agent-browser。没有安装驱动或修改系统授权。 [浏览器截图](2026-11-23-mobile-web.png)

0.9.1 的 H05 检查经认证的产物 API 发出目录和空文件打开请求，只从进程元数据确认唯一中文文件名出现在 Notepad 窗口标题。当时目录窗口尚无充分证据，Computer-use 工具初始化失败；没有改系统权限或启用产品电脑驱动。[当时结果](2026-11-23-artifact-open-before-visible-fix.json)

0.9.2 在窗口工具恢复后复验，定位到产物打开函数使用了后台 `windowsHide:true`。移除此项后，`sky.list_windows` 返回唯一中文目录的文件资源管理器窗口和空文件的 Notepad 窗口，证明经原 API 真实打开。稍后的内容捕获时目录窗口已消失，不据此声称观察过目录内容。[修复后证据](2026-11-23-artifact-open.json) · [修复前记录](2026-11-23-artifact-open-before-visible-fix.json)

Windows 回归改用本机支持的目录 junction 并保留穿越、链接和外部记忆断言。Python 参考脚本及缺陷变异显式使用 UTF-8，旧学习夹具按本机路径匹配。等待确认测试直接设置已过期的保存时间，覆盖不提前执行、暂停和不重复补预算。恢复测试分别等待创建和恢复进程，核对 `SIGKILL` 实际退出信号，并在关闭后清理夹具。前一轮 `npm run check` 215/215 通过。加入预检后，全量首轮通过 216 项，双子任务恢复测试在原 30 秒整项时限处取消，零跳过。该测试复用分阶段等待后定向通过，类型检查和构建通过。

macOS 待办菜单已接入任务状态和待补充问题，接回原任务同步通知已读。6 个 Swift 文件通过语法解析，原生编译和界面冒烟需 macOS。任务详情现在显示 Skill 的固定版本、读取记录和每次脚本执行回执，同时保留任务累计用量、压缩和返工次数。新增断言覆盖实际 Bash 失败后成功的两个回执。
