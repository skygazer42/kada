## 确定性与浏览器检查

功能矩阵覆盖真实 Pi/SQLite、本地 HTTP/MCP、原始文件检查、并发修改、进程强杀、恢复与取消。最终命令及数量以旁边的结构化验证清单为准；新增休眠跨周期回归也纳入同一矩阵。

独立复核发现的远程权限、压缩回放、旧链接、MCP 凭据回显、记忆引用时机、Skill 受理顺序、取消竞争和跨工作区变化判断均有失败用例及修复后的通过记录。用户目录 Skills 进入统一目录，历史任务保留原路径记录语义。

移动 Web 在 390 × 844 的实际 Chromium 浏览器中验证配对、发送、唯一回复，以及退出后重新配对接回同一会话。内置浏览器 MCP 不可用，使用已安装的 agent-browser。没有安装驱动或修改系统授权。 [浏览器截图](2026-11-23-mobile-web.png)

## 硅基流动实际结果

- [模型/MCP/Skills/新输入复用](2026-11-23-assistant-tools.json)：DeepSeek-V3.2，32 次总请求上限内完成 28 次请求，其中含一次模型目录查询。两次脚本结果分别为 42、17，固定版本相同，各有一次成功的真实脚本执行。供应商返回用量合计 89,792 token。
- [记忆管理最终复测](2026-11-23-assistant-memory-focused.json)：DeepSeek-V3.2，4 次模型请求、13,174 token。两个项目、纠正和遗忘验证通过；另从原始 Pi 回复独立核对两条应使用英文的回复，没有中文混入。
- [远程交付](2026-11-23-assistant-remote-final.json)：经过网页协议受理、重复消息查询、任务说明确认与文件下载，内容和哈希独立核对。
- [交接/提醒/双子任务](2026-11-23-assistant-memory-attempt-2.json)：相应三个场景通过；该轮整体失败如实保留，后续针对失败场景复测。

在线复用采用预先编写的合成 Skill。捕获、旧证明失效和回退由真实 Pi 的确定性用例覆盖，不把这次在线运行解释为自动学习质量或成本收益证明。压缩、失败尝试及子会话用量沿用 Pi；旧尝试没有独立保存的直连解析调用用量无法补算。金额均为未知，未把占位零价当作实际免费。

早期失败文件保留为 `assistant-*-attempt-*.json`。包含小模型把调用写成文本、测试目录隔离和断言问题，以及旧请求上限不足的尝试。报告中的通过只对应列出的用例，不覆盖未运行的实机条件。
