# 命名助手分配固定版本 Skill

本机用户可在助手配置中保存 skills 数组，每项是 Skill 名称和完整 SHA-256 版本。未配置时沿项目默认目录，空数组表示本助手不选 Skill。清空配置可恢复项目默认。配置由既有助手修订和变更回执持久化，用户在新任务选择该助手修订。

OpenMausBot 的 Bot 目录按 assignedSkills 读取共享库，并在指定 Bot 的入口修改分配。Kada 复用 Pi 的 Skill 解析、目录优先级与任务副本，把完整版本固定进原任务。跨助手与群组成员沿自己的工作区和权限读取固定副本。 [OpenMausBot 共享库归属](https://github.com/milind-soni/OpenMausBot/blob/3aec210054cd/server/host/skills-library.ts#L85) · [Bot Skill 分配入口](https://github.com/milind-soni/OpenMausBot/blob/3aec210054cd/server/routes/bot-skills.ts#L55) · [Rakazo Skill 路由](https://github.com/elie222/rakazo/blob/e64d73292179/packages/core/src/skills/agent-skill.ts#L401)

- Assistants 保存可选的精确版本引用。现有配置和历史回执在字段缺省时保留原行为。API、终端 JSON、普通聊天配置工具和项目助手设置页共同读写该字段。
- 新任务复制选定包并保存元数据。显式任务参数 skills 优先于助手默认。失效、停用或被同名项目包遮挡的版本在启动前返回错误。
- 根会话、被派活助手和本机群组成员可用既有 read 读取自己获授的 Skill 副本。包校验涵盖目录成员与字节，路径例外只允许读取该副本。其他文件操作沿原工作区和工具范围检查。
- 启动任务后的目录更新、助手修订和撤回不替换原副本，重启接回也沿已保存的副本。配对群组会话继续按原共享聊天权限执行。

实现顺序为助手数据契约与保存回归、任务固定与原生读取、跨助手和群组工作区、配置界面和用户说明。验收同时检查原 Skill 字节、原任务身份、越界读取拒绝和旧配置兼容。

## 实现范围

分支为 Fork 的 `codex/assistant-plan`。配置的所有入口共用 Assistants 的修订与回执；选择和复制沿用 SkillStore、pinSkills 与 Pi 原生目录格式。根会话、协作者和群组成员各自持有固定副本；跨项目的例外仅允许读取所获授包内的完整性已核对文件，不授予包写入或其他工作区访问。群组把嵌套的包状态复制出 Pi 事务，避免事务结束后继续引用其覆盖层。普通聊天和准备阶段不提示调用不可用的脚本工具。

## 当前验证

类型检查通过。九个相关测试文件的 45 项回归通过，包含原任务重启、显式空选择、被修改包拒绝、其他成员包拒绝、只读范围、managed 发布修订及撤回、跨项目返工、群组重启和配对聊天隔离、普通聊天配置及项目网页 API。没有 read 权限的角色不展示方法路径或不可用工具提示，主会话与聊天均完成了受限流程。

独立审查另复现了缺省配置没有为普通聊天、协作者和群组固定项目默认包的问题。新建这些任务时统一使用原 pinSkills 的缺省选择，仍不在助手配置中写入 skills 字段；已有历史任务的接回继续沿原元数据。三条新增回归先失败，修正后九个文件的 48 项相关回归全部通过，并检查恢复默认、重启及原包返工。

补充检查在 Windows 上复现了路径大小写改变后漏过原包校验的问题。路径归属改用平台的相对路径语义，大小写别名仍进入同一包校验；相关 26 项 Skill 回归通过，同时覆盖原生读取、脚本、捕获和导出。

Chromium 经已安装 agent-browser 验证：多项选择保存和重载；重复选择同名版本被拒绝并保留输入；空选择保存为 `[]`；恢复项目默认后删除配置字段；停用后的原版本显示暂不可用，编辑说明并重载仍保留原引用。 [浏览器记录](../../experiments/2026-11-27-assistant-skills-browser.json)

本项只验证本机分配和固定包行为。跨用户在线 Skill 库、原生手机配置及真实模型使用方法后的收益仍待验收。仓库全量检查另外记录，不以本项聚焦回归推断全面对齐。
