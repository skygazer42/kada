# 命名助手的默认浏览器配置

Status: implemented. 本项沿完整参考能力对齐目标推进，基线为 `e9e0f39`，功能提交为 `5104fd0`。

## 用户得到什么

用户在助手设置中选好已有的工作或个人浏览器配置；以后直接打开该助手的任务，或由已分配该助手的例行规则启动任务，会选择对应浏览器。Owner CLI/API、普通聊天配置工具与项目助手页面共用同一字段。旧任务继续使用开始时的浏览器和用户控制状态。

## 固定源码依据

- [OpenMausBot 的实际 PATCH 入口](https://github.com/milind-soni/OpenMausBot/blob/3aec210054cd/server/routes/bot-patch.ts#L403) 使用 profile 目录校验选择，并在写入前复查原浏览器状态。
- [已有 profile 的解析与接管约束](https://github.com/milind-soni/OpenMausBot/blob/3aec210054cd/server/bot-browser-profile.ts#L24) 不为未知名称自动创建浏览器，也不在活动回合中更换原会话。
- [助手自行换 profile 的限制](https://github.com/milind-soni/OpenMausBot/blob/3aec210054cd/server/profile-requests.ts#L27) 将当前操作和未来配置区分。
- [Host 的实际会话归属](https://github.com/milind-soni/OpenMausBot/blob/3aec210054cd/server/host/browser.ts) 与 [成员/群组分区测试](https://github.com/milind-soni/OpenMausBot/blob/3aec210054cd/server/host/browser.test.ts#L747) 是后续团队浏览器执行的参照；只读选择 helper 不是完整实现证据。

Pi 核对为已安装 1.4.0 的 `dist/harness/registry.js` 与 `configure`：当前 Kada 已在每个任务安装所选 ComputerBridge 的薄扩展，用 Pi 保存工具调用、等待和恢复。本项复用现有 `forTask`、租约、驱动指纹、browser-sign-in 和控制权记录，不另造执行或路由系统。

## 契约

1. 助手定义增加可选 `browserProfile: string`，语法复用已有 browserProfilePattern。缺省继续使用任务或宿主的既有默认；更新时 `null` 清除，省略保持。配置保存与原请求回执继续原子写入，重放先返回原结果，不因之后配置或驱动目录变化重写历史。
2. 创建或修改该字段时，名称必须存在于当前宿主的已配置目录；无需在线，也不连接驱动。原选择消失后仍可读取、归档或修改其他字段。启动任务时按最终生效的选择核对目录与驱动，不能静默换成其他 profile；有效的显式覆盖不受失效的助手默认阻挡。
3. 直接任务优先级为显式任务参数、关联工作继承的原有效选择、助手默认、原宿主默认。创建请求摘要继续只包含用户实际提交的参数，先按原 taskId 重放，再检查当前助手，避免配置更新破坏旧回执。
4. 新任务保存实际 profile、session 与 driver 指纹，助手快照同时保留其配置。后续角色编辑、归档、profile 改名或驱动替换不改旧任务。继承源助手的关联工作使用源任务的实际选择；没有显式覆盖时拒绝换掉源任务已固定的驱动。
5. 普通聊天保存选择，但仍没有电脑执行工具。转入已确认 Goal 后沿原选择执行。现有例行任务分配通过同一个 create 路径取得助手默认，发生项、预算及恢复不新建另一套状态。
6. 协作者已有 privateExtensions 排除 local_computer，群组已有独立的文件工具范围；本次配置不增加它们的电脑能力，也不借主任务浏览器代行。保存到成员快照的配置只解释未来默认，不能充当权限。团队的各自浏览器工具及接管仍是明确未完成的后续能力。
7. 项目设置和聊天配置目录只提供 profile 名称与连接状态，不提供环境变量、凭据、会话租约或驱动命令。未连接候选显示状态，原来保存但不在目录的值保留并标注不可用；保存失败保留草稿。选择 profile 不意味着增加工具权限。

## 实现落点与检查

Assistants 保存与公开读取负责语法和保存时目录校验；LocalRuntime.create 负责实际优先级、最终选择的可用性与固定。普通聊天目录和项目页面复用同一来源。CLI 角色管理沿当前严格字段 API，旧后台对未知字段明确失败；不会新建隐式兼容或自动切换。

测试覆盖存储/清除/重放、目录失效、两助手不同驱动、显式覆盖、原普通聊天确认、例行分配、原任务重启/接管、关联工作继承实际覆盖及驱动替换拒绝。原有协作者、配对群组和远程入口不能得到电脑能力。使用现有合成 MCP 驱动跑自动回归，再用已安装 agent-browser 和两个本地合成页面验证实际浏览器会话及设置页面。

## 已知差距

本项不等于云电脑、OS 沙箱、成员独立浏览器工具、跨主机执行或真实账号登录验收；能力矩阵分别记录。普通配置继续默认关闭，不自动安装驱动、创建账号资料或请求系统权限。
