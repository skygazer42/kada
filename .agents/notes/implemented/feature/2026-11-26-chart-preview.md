# Agent Note: 图表预览沿原交付证据

Status: implemented

## Problem

完成任务后用户需要从已验收的同一份数据查看交互图、读数和下载 PNG。原工作区文件可能在交付后改动。

## Decision

本机已确认的 Pi 任务用 `save_chart` 写入图表规格。原交付验证保留文件证据，创建预览链接前再次核对哈希，将解析后的结构化快照保存在本机有限期链接中。浏览器用同一数据绘图、显示原表和导出 PNG。 [参考实现和验收](../../../../docs/superpowers/plans/2026-11-26-chart-preview.md)

## Alternatives considered

直接打开任意模型生成的 HTML 可接受更多图表样式，也会运行文件中的主动内容。结构化图表让宿主掌握绘制和交互，分享页面的产品能力可在独立路径实现。

## Consequences

源文件被修改后无法生成新的旧版链接，原有有限期链接仍展示它绑定的验收快照。自动化检查原交付及非法规格，真实模型与浏览器检查数据、系列切换和 PNG。
