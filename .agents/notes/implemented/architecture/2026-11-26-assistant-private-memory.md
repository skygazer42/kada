# Agent Note: 命名助手在原任务中固定记忆范围

Status: implemented

## Problem

同一项目的不同角色可能被用于独立主题。用户要在未来的同一角色会话调用已经保存的事实，同时管理原申请、复核和原始对话。

## Decision

私有角色按稳定助手 ID 复用独立的 UserMemoryStore，直接保存原用户证据。项目记录和复核政策由已有目录维护，私有和共享操作通过同一个文件锁核对政策。新任务固定原角色配置，记忆注入、工具检索、复核回执、原对话和任务目录读取对应范围。owner 使用项目与角色 ID 管理记录，已经归档或改动范围的角色沿原 ID 管理已存事实。 [角色快照](2026-11-26-named-assistant-scope.md) · [实现与验收](../../../../docs/superpowers/plans/2026-11-26-assistant-private-memory.md)

## Alternatives considered

在公共索引增加角色字段可以复用一次文件扫描，搜索及复核入口都需要在同一份数据上持续过滤。独立目录复用保存、证据和复核实现，并让查询入口先选择作用范围。

## Consequences

只有直接启动的本机角色使用这个选择。共享工作区文件及用户明确授予的交接继续按实际工具范围处理。私有历史在切换角色模式后保留原任务的归属，同一角色的新私有会话仍可读取同一范围。
